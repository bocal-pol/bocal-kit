TEAM‑DEV

Main orchestrator for the dev cycle. It routes to the right agent, or runs a full cycle end to end.

/team-dev <mode> [context]
--full runs scoping, architecture, build, quality and release in sequence, until no blocking finding remains. No manual steps.

Smart routing

--autoteam-selector picks the agents for you
--fullfull cycle, start to end, no manual steps
--auditread-only → ranked remediation plan
--ask <skill>call a named skill directly
--queryask the project graph an architecture question
--graph-impactcheck a file's change impact

Product & architecture

--bootstrapproject bootstrap kit (App Spec, Brand, Backlog)
--product -prjproduct scoping: brief, PRD, specs
--architecture -archtarget architecture, ADRs, stack choice
--sprint -sprintsprint planning & estimation

ICT DIRECTOR

Independent orchestrator. Full ICT service management: network, support, security, infrastructure, bulletins, inventory.

/ict-director [--mode|-alias] [target]
Independent of team-dev — call it directly as /ict-director. A leftover line in the agent's own file still says team-dev --ict-director; that flag does not exist. Ignore it.
