# Diagram

## Effect
Generic explanatory diagram, simple shapes connected by lines/arrows, no frills.

## Imposed structure (non-negotiable)
- Simple geometric shapes (rectangles, circles)
- Labeled arrows connecting the shapes
- White background, clean whiteboard style, minimal palette

## Positive Prompt (English skeleton)
`clean explanatory diagram of {{subject}}, simple geometric shapes connected by labeled arrows,
whiteboard style, minimal color palette, high clarity`

## Negative Prompt
`photorealistic rendering, decorative clutter, watermark, blurry`

## Variables to collect
1. Concept/process to diagram?
2. Number of steps/elements?

## Combinable with
- `flowchart`, `mindmap`, `infographic`

## Example
Subject "how a REST API works" → client, request, server, response connected by arrows.
