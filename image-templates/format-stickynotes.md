# Sticky notes — Stickynotes

## Effect
Breakdown into sticky notes, one idea per note, organized grid on a wall/board.

## Imposed structure (non-negotiable)
- Colorful sticky notes (3-4 colors), slightly misaligned grid layout
- One short handwritten phrase per note
- Whiteboard or wall background, office-brainstorm photo style

## Positive Prompt (English skeleton)
`sticky notes brainstorm board about {{subject}}, colorful post-it notes arranged in a loose
grid on a whiteboard, one short handwritten idea per note, slightly imperfect alignment, casual
office brainstorm photo style`

## Negative Prompt
`single note only, typed text, perfectly aligned grid, watermark, blurry`

## Variables to collect
1. Brainstorm topic?
2. Number of ideas/sticky notes (5 to 12)?

## Combinable with
- `handwritten`, `mindmap`

## Example
Subject "content strategy" → sticky notes for SEO, social, paid ads, email, CRM.
