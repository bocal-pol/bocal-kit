# Dashboard

## Effect
Converts the subject/data into a UI dashboard interface.

## Imposed structure (non-negotiable)
- App-style interface (light or dark mode)
- Grid of widgets: charts, gauges, stat cards
- Consistent UI palette, clean sans-serif typography

## Positive Prompt (English skeleton)
`UI dashboard visualization of {{subject}} data, interface with grid of widgets: line charts,
gauges, stat cards, consistent modern UI color palette, clean sans-serif typography, realistic
app mockup`

## Negative Prompt
`hand-drawn style, cluttered inconsistent widgets, watermark, blurry`

## Variables to collect
1. Data/theme to visualize?
2. Light or dark mode?

## Combinable with
- `infographic`, `isometric`

## Example
Subject "fitness tracking" → daily steps widget, heart rate, calories, weekly chart.
