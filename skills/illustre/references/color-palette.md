| Accent title | `#0066CC` | Important subtitles |

## Structural Elements

| Element | Color |
|---|---|
| Arrows | Inherits the source element's stroke color |
| Structural lines | `#334155` |
| Reference points (dots) | `#0066CC` (fill) / `#0047CC` (stroke) |
| Canvas background | `#FFFFFF` |
| Slide separators | `#CCCCCC` (dotted) |

---

## Application Rules

1. **Use a very pale Fill** — dark fills overwhelm the text
2. **Stroke always darker** than the matching fill
3. **Never more than 3 shape colors** in a single diagram
4. **White background only** — no global colored background
5. **No gradients** — flat colors only in Excalidraw
