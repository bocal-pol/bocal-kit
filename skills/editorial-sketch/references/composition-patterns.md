# Composition patterns and originality rule

## Base structure types

Choose a single structure type — don't mix them.

### Workflow (process)

Good for: input -> processing -> output, content production, AI workflow, automation chain.

Composition: input on the left, the character or a strange machine in the center processing, output
on the right, orange arrows for the main flow.

### System component

Good for: information source, filter, database, rendering engine, part of an agent system.

Composition: draw only 3 to 5 central modules, the character takes part in one of the key gestures.

### Before/after

Good for: chaos/order, manual/automatic, scattered/gathered, anxiety/stability.

Composition: chaos on the left, stability on the right, orange arrow in the center. Characters can
be more expressive.

### Character state

Good for: user pain point, creator state, too many tools, information anxiety, from stuck to
started.

Composition: 2 to 4 small states, one short annotation per state.

### Conceptual metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, automatic
daily report.

Composition: one large object or strange machine, few inputs, a single output. Must have a
memorable point.

### Methodological stack

Good for: methodological framework, system hierarchy, skill stack, content system layering.

Composition: boxes stacked layer by layer, not a formal pyramid; the character carries bricks or
builds alongside.

### Path / map

Good for: from idea to launch, user journey, content transmission path, learning journey.

Composition: a winding path, few nodes, the character pulls a thread or walks on it.

### Small panel storyboard

Good for: from failure to success, real process, a rant, before/after usage change.

Composition: 2 to 4 small scenes, each panel shows only one action.

## Original metaphor generation method

Each time, reinvent the metaphor from the current text — never copy a past image.

### Three steps

1. Replace the abstract concept with a concrete physical action: getting stuck, fleeing, getting
   heavier, sorting, settling, fermenting, opening, folding, unpacking, flowing back.
2. Replace the system's structure with a low-tech object: a broken machine, a cardboard box, a
   drawer, a pipe, a mailbox, a weird dial, a scale, a well, a ladder, a strange workstation.
3. Make the character carry the action: not standing beside it, but stuck in the machine, pulling
   the wrong thread, guarding a door, carrying, repairing, weighing, holding a ladder, taking notes,
   pushing something into a weird device.

### Usable object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of
  thread, valve, turntable, black box, hole puncher, press, clothesline, strange workstation.
- Pick only 1 to 2 at a time — don't overload.

### Character action pool

- Pull, carry, push in, fish out, press, weigh, sew, cut, screw, guard, push, receive, disassemble,
  mark, retrieve.
- The action must serve the central meaning — not be strange just for the sake of it.

## Anti-copying rule

Don't open or copy the content of `assets/examples/` by default. These images are only for style
calibration — line density, empty space, color restraint, character temperament.

Unless the user explicitly asks ("reproduce this one / copy this composition / start from this
example"), never directly reuse a composition already seen:

- The two breaking points of a conveyor belt
- The character pulling a decision lever inside a content machine
- The character turned into a funnel sorting traffic/trust/conversion
- The character cutting up a material-fish
- The character holding the thread of a transmission path
- The character pulling three layers of information sources
- Three characters each holding a megaphone/building a bridge/opening a door
- The character stamping a toolbox of ready-made formulas
- The character holding up a sign in front of a trap-filled path

Even on a similar theme, change the metaphor. For example, "transmission path" doesn't have to draw
a route — you could draw the character connecting a piece of content's tail to a doorknob;
"reusing the same element multiple times" doesn't have to draw a fish — you could draw the character
squeezing a ball of paper into several different shapes.
